# Домашнее задание к блоку «Props и TypeScript в React» — Задача «Список предложений»

Веб-приложение для интернет-магазина, реализующее вывод каталога предложений (Listing) с использованием статической типизации на TypeScript и интеграцией внешних данных в формате JSON.

### 🚀 Функциональность и архитектура

Приложение построено на базе строгого компонентного подхода React 19 с использованием TypeScript 5+, исключая использование типа `any` и гарантируя безопасность данных на этапе компиляции:

* **`App` (Контейнерный компонент):** Отвечает за импорт сырых данных, предварительную фильтрацию активных объявлений (`item.state === "active"`) и передачу очищенного массива в презентационный слой.
* **`Listing` (Презентационный функциональный компонент):** Принимает через свойства (`Props`) строго типизированный список предложений. Внутри инкапсулированы чистые функции форматирования бизнес-логики:
  * Ограничение длины заголовков до 50 символов с добавлением знака `…`.
  * Валидация кодов валют (`USD`, `EUR`, `GBP`) и вывод соответствующих символов без лишних пробелов.
  * Динамическое вычисление классов остатков на складе (`stock-low`, `stock-medium`, `stock-high`) по объёму доступного товара.

## 🛠️ Технологический стек

* **Frontend:** React 19, TypeScript 5+, JSX
* **Сборщик:** Vite 8
* **CI/CD:** GitHub Actions (автоматическая сборка пакета `dist` и деплой на ветку `gh-pages`).

## 🔧 Локальное развертывание

1. Установите зависимости:

   ```bash
   npm install --legacy-peer-deps
   ```

2. Запустите сервер для разработки:

   ```bash
   npm run dev
   ```

3. Откройте локальный адрес в браузере: `http://localhost:5173`
